# Lisp Metamorphism and Homoiconicity
A homoiconic, meta‑circular system that rewrites its own structure

Start: -

---

Context

Lisp is the second language I’m learning (after Prolog), and it resonates with me for the same reason: it is a core substrate for symbolic reasoning, metamorphic systems, and meta‑level computation.  

Where Prolog explores metamorphism through rules, clauses, and evaluation strategies, Lisp explores metamorphism through AST rewriting, macro transformation, and meta‑circular evaluation.  

Together, Prolog and Lisp form parallel investigations into metamorphism and homoiconicity, each providing a different representational foundation for symbolic self‑modification.

---

Purpose

This project explores:

- homoiconicity  
- AST rewriting  
- macro‑driven transformation  
- meta‑circular evaluation  
- syntactic metamorphism  

The aim is to build a Lisp system that can:

- introspect and transform its own code structures  
- rewrite its own AST under constraints  
- modify its own macro expansion behaviour  
- experiment with evolving syntactic and semantic strategies over time
